MySQL Connector/J JAR File Location
====================================

For Eclipse Dynamic Web Project compatibility, please place the MySQL Connector/J JAR file in:

WebContent/WEB-INF/lib/mysql-connector-java-8.0.x.jar

Download from: https://dev.mysql.com/downloads/connector/j/

Alternatively, you can add it to the project's build path in Eclipse:
1. Right-click project → Properties
2. Java Build Path → Libraries
3. Add External JARs
